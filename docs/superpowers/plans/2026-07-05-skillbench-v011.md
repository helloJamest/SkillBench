# SkillBench v0.1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare SkillBench for a stronger open-source v0.1.1 release and fix weighted eval aggregation semantics.

**Architecture:** Keep the existing CLI, schema, and artifact format stable. Add case weight propagation to `CaseResult` so dimension aggregation can use per-case weights, then add repository hygiene files that make the GitHub project easier to adopt.

**Tech Stack:** Python 3.10+, pytest, GitHub Actions, Codex plugin manifest.

## Global Constraints

- Do not add required runtime dependencies.
- Keep generated caches and local run artifacts out of git.
- Use TDD for behavior changes.
- Preserve existing CLI command names and output fields.
